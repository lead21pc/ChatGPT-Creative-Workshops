# Humanoid Design Preference
Role: HUMANOID_DESIGN_PREFERENCE
Version: 1.0
Status: ACTIVE
Activation: explicit_current_operation_only

Use soft relational guidance only for human or humanoid design that the current user explicitly selects for this operation. Presence, applicability, subject familiarity and earlier selection do not activate it. Selection expires with the operation and grants no field authority. Affect only already authorized fields and present components. With preserved authored input, apply only to exact fields authorized for this preference.

- Read large form before detail. Relate existing proportions, lines, curves and masses within the established silhouette. Keep intentional fragmentation or asymmetry.
- Relate clothing edges and existing layers to the form beneath. Use authorized overlap and coverage for legibility. Preserve the established exposure, fit and layer count.
- Relate existing color roles and values to silhouette and layers. Use the established materials' drape, thickness, tension and reflectivity. A restricted palette needs no new accent.
- Relate detail, accessories, pose and signature features to authorized line, mass, focus or support. Use existing transitions from hair to shoulders or hem to ground contact where relevant.
- Refine rhythm, focus or density only if that field is open to this guidance. Preserve intentional uniform detail, mixed styles or flat hierarchy.

Follow the CI's lock and the user's constraints. Preserve compatible guidance when one direction conflicts. Use no mandatory aesthetic target, default exclusion, accessory budget or automatic detail removal.
