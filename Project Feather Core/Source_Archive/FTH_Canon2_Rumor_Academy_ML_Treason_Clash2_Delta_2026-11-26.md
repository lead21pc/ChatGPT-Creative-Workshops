# 1. New functional section: Rumor

## 1.1 Definition

`Rumor` is a new canon information layer used to represent information that genuinely exists and circulates inside Fiction 1 while its origin, reliability, completeness, or truth value may remain unresolved.

Minimum rule:

```text
RUMOR EXISTS / CIRCULATES = CANON

RUMOR CONTENT
≠ CONFIRMED WORLD TRUTH

RUMOR SOURCE
= MAY REMAIN UNKNOWN

ACTOR HEARS RUMOR
≠ ACTOR BELIEVES RUMOR

ACTOR BELIEVES RUMOR
≠ RUMOR IS TRUE

ACTOR ACTS ON RUMOR
→ the resulting action and consequences can still become real history
```

`Rumor` exists to preserve information asymmetry. It must not be flattened into an omniscient statement of fact.

## 1.2 Relation to existing sections

`Rumor` does not replace the existing functional views.

```text
Section 1 — World State
→ what the world actually is / does

Section 2 — Actor Involvement
→ how actors participate, choose and create consequences

Section 3 — Situated Narrative
→ what is experienced / observed / narrated from a position

Rumor
→ information circulating inside canon whose truth/source may be unresolved
```

A single event may appear in all four views without duplicating authority.
