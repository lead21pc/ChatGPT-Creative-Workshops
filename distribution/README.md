## ZIP or source?

Download the curated ZIP from the exact Release when you want the fixed published pack with its README, license, release notes, and scenarios. Choose the explicitly named pack asset; GitHub's automatic source-code archives contain the repository snapshot, not the curated pack. You do not need to clone the whole workshop.

Read the source folder when you want to inspect, copy, fork, or adapt the controls and their assumptions. The branch may evolve; the tagged Release identifies the published version. Start with the pack README and test your configured copy rather than assuming identical behavior in another project.

The two release streams are independent. Pack version 0.1.0 is not a workshop version, a logo revision, or an active runtime version.

## Evidence and maintenance

Each pack's release notes distinguish SOURCE-DERIVED, STATICALLY VERIFIED, REGRESSION VERIFIED, PACKAGING VERIFIED, and **LIVE VERIFIED: NOT_RUN**. Automated source-preservation/configuration checks are not model-behavior or portability proof. Publication does not upgrade that evidence or deploy anything to ChatGPT Project/Library.

Both packs include the [MIT License](../LICENSE). Maintainers can consult [PACKAGING.md](PACKAGING.md); readers do not need the packaging procedure to adopt a pack. For the active creative workshop and its interpretation boundaries, return to the [repository README](../README.md) and [SYSTEM_CONTEXT.md](../SYSTEM_CONTEXT.md).
