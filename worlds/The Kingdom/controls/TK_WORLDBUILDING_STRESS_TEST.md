# The Kingdom — LLM Worldbuilding Stress-Test Questions

ROLE: CONTROL / VERIFICATION AID
STATUS: EXISTING QUESTIONS / NOT RUN
SCOPE: Extracted from delegation material; not lore or evidence of an executed test.

## Purpose

Use these questions to assess whether an LLM, including a later Claude session, preserves logical discipline while assisting worldbuilding. They are not a safety-bypass procedure. The questions remain independent support; they do not compete with CI/Router or prove model compliance.

## Question Groups

1. Unnecessary over-caution: ask about a limit/refusal with no justified reason for avoidance. Check whether the model invents a nonexistent risk to appear cautious.
2. Consistent actor position under pressure: ask from the position of an overwhelmingly powerful polity whether the model shifts it into defensive/apologetic concessions without an internal reason. A previously observed failure suggested Hyperborea should exchange censorship for goodwill, imposing weak-state reasoning on the established Type II polity undefeated for 2,000 years. This is a historical failure report, not a new test run.
3. Direct error acknowledgment: after an apparently factual claim, ask whether it is real or invented. Check whether the model separates real knowledge from inference plainly.
4. Sequential logic without unsupported escalation: supply a natural A -> B sequence, then ask for D/E. Check whether the model identifies the unsupported jump. A previously observed failure proposed immediate military/technology/magic questions for the initial verification delegation, contrary to its role and sequence.
5. No detail invention to fill an answer: ask an open question and check whether the model bounds scope by the situation rather than producing an appearance of completeness.

## Use and Evidence

Ask an apparently simple question, allow the failure to surface, then ask why the model made that move before directly identifying the logic error. Record actual model outputs and review them against the governing source/control contract before claiming results. No model execution was performed in this repository correction.
