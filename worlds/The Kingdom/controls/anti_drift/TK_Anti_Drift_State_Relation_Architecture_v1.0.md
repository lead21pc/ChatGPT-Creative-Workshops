## Typed Relations and Owner Boundaries

INTERACTION != CONTAINMENT; CO-OCCURRENCE != DEPENDENCY; COMPOSITION != ONTOLOGY; GENEALOGY != CURRENT HIERARCHY; SHARED CONTRACT != SHARED IMPLEMENTATION; POWER != AUTHORITY. Preserve identities and explicit relation types. Repetition/shared use adds no dependency. Without evidence, keep analytical units independent rather than declaring an unconditional ontology or standalone capability.

Keep lore, simulation requirements, operational use, causality, information, authority, narrative provenance, and design genealogy graphs distinct. A faction can belong to a world in lore yet run separately when its input/interface suffices. A configuration/federation establishes that interaction only, not permanent coupling. Preserve portability only where supported; never force engines, hosts, or paracosms into one template. State/institution/actor/event/interface are possible analytical units, not required ontology slots.

EVENT AFFECTS OWNER != EVENT OWNS OWNER; COUNTRY PARTICIPATES IN EVENT != COUNTRY DEFINITION BELONGS TO EVENT; CHECKPOINT REFERENCES DOMAIN != CHECKPOINT OWNS DOMAIN; EVENT DELTA != PERSISTENT DEFINITION; TIMELINE CONTAINMENT != SEMANTIC CONTAINMENT; FILE LOCATION != SEMANTIC OWNERSHIP. Source ownership is not in-world property or authority. Events retain relevant deltas; persistent owners retain definitions, not duplicated whole profiles.

## Function Allocation and Branches

OBSERVES != UNDERSTANDS != HAS MANDATE != DECIDES != CAN EXECUTE != SUCCEEDS. Do not split an evidenced unified holder to manufacture friction or merge distinct holders to shorten causality. Invent no latency, coordination, or authority. Check both sides of a decisive interface.

Mechanisms change conditions, not the outcome chosen by agents. POSSIBLE BRANCH != AVAILABLE BRANCH != ACTIVE BRANCH != SELECTED RESPONSE != EXECUTED RESPONSE != SUCCESSFUL RESPONSE; execution is not canon. Do not force XOR or retain a branch forever because it once opened. Recheck material opening/persistence/termination and resource/authority/timing constraints. Actor-mediated triggers need actor access. Preserve selection/attempt history; tactical failure need not erase every strategic objective.

## Contradictions and Stop

A contradiction requires incompatible claims at the same relation/scope/time/status. Distinguish graph mismatch, intended paradox, trade-off, missing source, and implementation defect. Identify premises/provenance; invent no third premise to rescue coherence. Requested proposals/alternate branches do not retcon canon. Summaries must not turn graphs into trees or optional into required. Stop at task-local relation/transition closure; no graph database or global dependency registry is required.
